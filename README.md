# AgentRidge

> **Authorized targets only.** AgentRidge is Mission Control for autonomous pentests that run on *your* Mac or Windows PC — not another cloud black box.

## The hook

Most AI security tools talk.  
**AgentRidge acts.**

A commercial-grade **Agent Ridge Principal** reasons through the engagement, then drives local **Ridge Sub-Agents** that install tools, execute live, map the attack surface, inventory findings, and ship a client-ready PDF — with **no API usage billing**.

One annual license. Unlimited model usage. Written authorization required.

## What you get

- **Mission Control** — live progress, tool calls, workflows, stop anytime  
- **True attacker** or **Auditor** depth — you choose the mandate  
- **Cartography** — live attack-surface map  
- **Vulnerabilities** — CRITICAL → LOW, technical & non-technical views  
- **Reports** — Penetration Test & Security Assessment PDF
