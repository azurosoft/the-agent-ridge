# What is AgentRidge?

AgentRidge is a **desktop Mission Control** for authorized security engagements.

## Why it exists

Cloud “AI pentest” products often mean:

1. your scope leaves your perimeter,  
2. you pay per token / per call,  
3. you can’t see what the agent actually did.

AgentRidge flips that:

1. **execution stays on your machine**,  
2. **one Pro license** — no API consumption bill from Azuro,  
3. **every tool_call is visible** in Mission Control.

## The agents (branded)

- **Agent Ridge Principal** — commercial reasoning brain: chains techniques, narrates the path to impact.  
- **Ridge Sub-Agents** — local operators: install tooling and run the engagement on the workstation.

## Modes

- **True attacker** — deep push within the written mandate.  
- **Auditor** — proportionate, compliance-oriented testing.

## Who it’s for

Security consultancies, internal red teams, and auditors who already work under **written authorization** — and want an autonomous co-pilot that doesn’t hide behind a SaaS curtain.
