# Download AgentRidge

Official macOS installers are published as **GitHub Release assets** on this repository.

## Latest

Open: https://github.com/azurosoft/the-agent-ridge/releases/latest

| Asset | Arch |
|-------|------|
| `AgentRidge-*-arm64.dmg` | Apple Silicon |
| `AgentRidge-*-x64.dmg` | Intel |
| `checksums.sha256` | integrity |

## Install

1. Download the DMG for your Mac.  
2. Open it and drag **AgentRidge** to Applications.  
3. First launch: grant Accessibility + Full Disk Access when prompted.  
4. Sign in with the same account as [www.join-ridge.com](https://www.join-ridge.com/login/).

## Integrity

```bash
shasum -a 256 -c checksums.sha256
```
