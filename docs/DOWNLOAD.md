# Download AgentRidge

Official installers are published as **GitHub Release assets** on this repository.

## Latest

Open: https://github.com/azurosoft/the-agent-ridge/releases/latest

| Asset | Platform |
|-------|----------|
| `AgentRidge-*-arm64.dmg` | macOS Apple Silicon |
| `AgentRidge-*-x64.dmg` | macOS Intel |
| `AgentRidge-*-win-x64-setup.exe` | Windows x64 (setup) |
| `checksums.sha256` | integrity |

## Install — macOS

1. Download the DMG for your Mac.  
2. Open it and drag **AgentRidge** to Applications.  
3. First launch: grant Accessibility + Full Disk Access when prompted.  
4. Sign in with the same account as [www.join-ridge.com](https://www.join-ridge.com/login/).

## Install — Windows

1. Download `AgentRidge-*-win-x64-setup.exe`.  
2. Run the installer (Windows 10/11 x64).  
3. Sign in with the same account as [www.join-ridge.com](https://www.join-ridge.com/login/).

## Integrity

```bash
shasum -a 256 -c checksums.sha256
```
